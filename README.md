# 結婚式 Web 招待状

德嵩 千里 ・ 畠中 翼 結婚式のオンライン招待状です。

**公開日**: 2026年11月29日  
**会場**: JWマリオット・ホテル東京 28階

---

## ✨ 機能

- 🎁 **美しいデザイン** - 高品質な写真と洗練されたUI
- 📝 **簡単登録** - 出欠やアレルギー情報を入力するだけ
- 📧 **自動メール** - 登録完了メールが自動送信
- 💾 **データ管理** - Google Sheets に安全に記録
- 📱 **レスポンシブ** - スマートフォンからも見やすい
- 🔐 **セキュア** - リンク知識者のみアクセス可能

```

```
管理者用パスコード: 入籍記念日（YYYYMMDD形式）

## 📋 ご出欠登録の流れ

1. 招待状リンクを開く
2. 「ご出欠のご連絡」セクションまでスクロール
3. 出欠を選択して情報を入力
4. 「送信する」をクリック
5. 登録完了メールが届く ✉️

---

## 💌 自動送信メール

登録時に以下の情報を含むメールが自動送信されます：

- ✅ お礼のメッセージ
- ✅ 集合時間（12:30）
- ✅ 披露宴開始時間（13:00）
- ✅ 会場名（JWマリオット・ホテル東京 28階）
- ✅ 住所（〒108-0074 東京都港区高輪2-21-2）
- ✅ ホテル電話番号（03-3434-7070）

---

## 👨‍💼 管理者機能

### 回答状況の確認

管理者リンク (`?admin=1`) からパスコードを入力すると：
- ✅ すべてのゲスト回答を確認
- ✅ Google Sheets を開く
- ✅ データをダウンロード

### Google Sheets 自動記録

以下の情報が自動的に記録されます：
- タイムスタンプ
- 出欠状況
- ゲスト情報（名前・メール・電話・住所）
- アレルギー情報
- メッセージ
